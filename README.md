# KontoraVPN

Клиент VPN (Windows + Android) на **sing-box 1.14**: несколько ключей подписки, автовыбор рабочего, RU напрямую.

## Скачать

| Платформа | Файл |
|-----------|------|
| **Windows** | [KontoraVPN-Setup.exe](https://github.com/vladislov3r/Kontora-vpn-app/releases/latest/download/KontoraVPN-Setup.exe) |
| **Android** | [KontoraVPN.apk](https://github.com/vladislov3r/Kontora-vpn-app/releases/latest/download/KontoraVPN.apk) |

Все версии: https://github.com/vladislov3r/Kontora-vpn-app/releases

### Установка

- **Windows:** запустите Setup от имени администратора (нужно для TUN).
- **Android:** разрешите установку из неизвестных источников для браузера/файлового менеджера, затем откройте APK.

### Обновления

В приложении есть кнопка проверки обновлений — скачивает установщик с этой страницы Releases.

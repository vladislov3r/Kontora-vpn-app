# KontoraVPN

Клиент VPN (Windows + Android) на **sing-box 1.14**: несколько ключей, автовыбор, вкладка правил приложений.

### Установка

- **Windows:** Setup от имени администратора (нужно для TUN).
- **Android:** разрешите установку из неизвестных источников, откройте APK.
